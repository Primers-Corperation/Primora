# Primora Scripts & Tools

Utility scripts and build tools for Primora development and deployment.

## Build & Development
- `test_xaml.ps1` - XAML validation testing
- `convert_icon.ps1` - Icon conversion utility
- `tools/` - Build tools and utilities

## Deployment
- `Install-Primora.ps1` - Installation script for Primora
- `deploy.ps1` - Deployment automation
- `primora.bat` - Batch launcher

## Tools
- `tools/rcedit.exe` - Resource editor
- Additional build and development tools
